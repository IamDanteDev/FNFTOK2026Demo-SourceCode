# FNF: The Origami King 2026 Demo — Source Code

An **unofficial community project** of *Friday Night Funkin': The Origami King (2026 Demo)* source code

The project was reconstructed from the Windows version using [Godot Decompiler](https://www.decompiler.com/godot). This repository holds the recovered **source code and assets** only — no build artifacts.

**Disclaimer:** I am not affiliated with the original developers and have not received permission to redistribute this project. All original content belongs to its respective owners. If the development team has concerns, they can contact me through GitHub to discuss removal.

## Requirements

- [Godot 4.7](https://godotengine.org/) (Forward+ renderer)

## What is in this repository

| Path | Contents |
| --- | --- |
| `project.godot` | Godot project configuration, autoloads, input map |
| `export_presets.cfg` | Web, Linux and Windows export presets |
| `scenes/` | Scenes, character sprites and stage art |
| `scripts/` | Recovered GDScript sources (`.gd`) and bytecode dumps (`.gdc`) |
| `assets/` | Songs (charts and audio), fonts, UI resources |
| `cutscenes/` | Cutscene scenes and frames |
| `addons/2d_shapes` | Editor plugin used by the original project |

## What is not in this repository

| Excluded | Reason |
| --- | --- |
| `FNFTOK.x86_64` | Export binary, not distributed here |
| `FNFTOK.pck` | 389 MB data pack, exceeds GitHub's 100 MB per-file limit — published as a release asset instead |
| `.godot/` | Editor cache, regenerated automatically on import |

## Open the project

```sh
git clone https://github.com/IamDanteDev/FNFTOK2026Demo-SourceCode.git
cd FNFTOK2026Demo-SourceCode
```

Then import `project.godot` from the Godot 4.7 project manager. The first import rebuilds the `.godot/` cache and may take a few minutes for the full asset set.

The main scene is `res://scenes/states/menus/title_screen/title_screen.tscn`.

## Notes on the reconstruction

- Recovered scripts are GDScript 2.0 (Godot 4.x). `.gdc` files are decompiler bytecode dumps kept for reference; Godot ignores them at runtime.
- `export_presets.cfg` was generated by the decompiler. Its `Linux` preset references a custom export template named `Linux-2026Demo`, which is not part of this repository; clear the custom template field (or install it) before exporting locally.
- Behaviour that lived in the original engine's binary data cannot be recovered perfectly. Expect rough edges; fixes are welcome.
